# DeepSeek OCR (offline)

- Model folder: `models/deepseek_ocr/`
- Required files: `config.json`, `model.safetensors`, `tokenizer.json`
- OCR runner validates local files and never requires internet.
- In settings enable OCR mode `deepseek`.
- Test OCR call uses `deepseek_ocr.test_ocr(image_path)`.
